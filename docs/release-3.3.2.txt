Better Canvas 3.3.2 quality fixes

Visible changes
- Instructor tools (roster export, attendance buttons) appear only in courses where you teach. Roster CSV cells that start with a formula character are quoted.
- Course cards stay hidden when Canvas switches the dashboard to List View or Recent Activity.
- The grade weights donut draws each arc after the previous one instead of stacking them.
- The hidden assignment preview no longer blocks clicks on the links under it. Escape and scrolling close it, and it has its own switch.
- Reset keeps recurring tasks, tags, goals, credits, saved themes, custom links, course order, nicknames and hidden courses.
- Import checks the file first. A theme file gets its own message, and a backup asks before replacing sticky notes, drafts, planner data and grade history on this device.
- Tab and Shift+Tab leave the shortcut recorder instead of becoming the shortcut. Backspace or Delete clears a binding.
- A burst of typing in one settings field is one undo step.
- Sticky notes are never pruned. Empty lists go, and drafts expire after a week.
- Two tabs finishing the same Pomodoro phase start the break once, and the log records the minutes actually focused.
- Weekly recurring tasks need a weekday, monthly days clamp to short months, and a rule starts on the day it was made.
- The planner keeps keyboard focus through rebuilds, refreshes due labels each minute and fetches the new day after midnight.
- Toasts wait while hovered or focused and sit above the focus timer. At most one save-failure toast shows per minute.
- Desktop notification permission is asked when you switch it on. Reminders skip calendar events and announcements.
- Calendar export keeps real event times, gives each item a unique UID and a link, and ends all-day events on the next day.
- The syllabus scan matches real month names only, skips fractions, keeps table rows whole and remembers which dates you added.
- Module progress counts "complete one item" and completed modules the way Canvas does. After a failed request it waits a minute instead of asking again on every page update.
- Grade Tools shows Canvas's current grade, labels its own estimate, and keeps the final-exam inputs through rebuilds.
- Scene themes store short references instead of up to 1.2 MB of drawings in settings. Saved data URIs are converted on load.
- Scene theme cards each get their own composition. Cards shift the theme's hue and some are mirrored, and space themes change subject (planet, crescent moon, galaxy, comet, glowing core, rising planet) and horizon. Cosmic Bloom used to move blurred clouds around one picture.
- Scene themes draw the school logo in the accent colour on a clear tile instead of the school's black one. A logo with no transparency keeps its own colours, and keyboard focus on the logo stays visible. Hide, image and text logos are unchanged.
- Under scene themes the dashboard header scrolls with the page. Canvas pins it to the top, and as a floating panel it hung over the cards.
- New icon: a white B on a deep navy disc inside a ring of eight segments that shade from coral to rose. Each size is cut from one 1024 px master.
- The toolbar icon opens settings instead of a popup. On a Canvas page that's the settings drawer, and anywhere else it's the settings tab. On a school's own Canvas address the settings tab asks to allow it. The popup's version of that check never saw the address, because the extension had no access to the tab.
- The Edit Canvas preview is a scaled copy of the page you opened settings on, so it matches Canvas: the same header, cards, sidebar and To Do, with each change applied as you make it. A theme you're trying shows on the page until you apply or cancel it. The preview used to be a drawing with sample tasks. The settings tab still shows a sample, because it has no Canvas page to copy.
- Focus ring and Cursor settings show what each choice looks like. The focus ring setting says what it is: the outline on the link or button you reach with Tab. The cursor comes as an arrow, dot, ring or crosshair in any size from 16 to 48 px and any colour, with a box to try it. Large becomes the 32 px arrow. Applying a theme keeps your cursor and focus ring.
- Turning off Coming Up no longer hides Recent Feedback. Canvas draws both lists from one template, and the Coming Up rule matched both. A new View Grades switch hides that button, in the sidebar or in Canvas's newer dashboard header.
- Dark mode no longer fades buttons on rescans, darkens new content before it paints, keeps equation images readable and leaves the rich-content editor light. Dark text stays on mid-tone chips and cells, and pinned links pass 4.5:1.
- Text on Canvas primary buttons and the skip link uses the accent's contrast colour, so a light accent no longer puts white text on a light fill.
- Color-blind modes shift confusable colours toward ones you can tell apart instead of simulating color blindness.
- Study time counts active, focused seconds and is added up in the background, so short visits count and idle tabs don't.
- Quiz drafts belong to one attempt. Submitting clears every page's draft with one background message, which a fast navigation can't interrupt. A cancelled submit keeps them, and if a submit doesn't go through, saving resumes.
- Lists in settings reorder by touch from a 24px grip, as well as by mouse and arrow keys.
- The settings sidebar hides its scrollbar, which pushed the on/off card and the buttons off centre. It still scrolls.
- The toolbar count clears once no Canvas tab is left to keep it current.
- My locker is gone. Its notes, bookmarks and flashcards copied a feature from another Canvas extension. Anything saved in it stays in the browser's extension storage, but nothing shows it anymore.
- The settings workspace and photo theme data load on first use. Each Canvas page parses 638 KB of script instead of 933 KB.
- The bundled anime artwork ships as WebP: 2.4 MB instead of 13.5 MB. Each package is 2.7 MB.
- New installs start with the reading bar and Speak buttons off. Switches stay beside their labels at phone width, and Apply theme stays on screen.
- Your settings and local study data stay on this device. Image searches send your query to api.openverse.org. Photo themes and previews load images from third-party hosts. No telemetry.

Verification
- 155 automated tests passed in each of three consecutive runs of node --test "tests/*.test.cjs".
- All 57 extension JavaScript files passed node --check. Both packages built, passed zip integrity checks, store paths with forward slashes so macOS unpacks them intact, and contain the manifest and four WebP images, with no tests, package files or node_modules.
- Headless Chrome for Testing 156.0.8078.4 passed 15 unpacked-extension checks and 47 studio checks with no runtime errors. They include lazy loading into the content-script world, a cold settings open, concurrent tab storage, a cancelled and a real quiz submit across navigation, a touch drag on a real grip, and a scene dashboard header that scrolls away.
- Firefox 158.0 passed 9 checks of the built Firefox package through geckodriver 0.37.1: install, content scripts, the lazily loaded settings drawer, a theme saved through the background surviving a reload in dark mode, the scene tint on a cross-origin SVG logo, the WebP atlas and wallpaper, and quiz drafts through a cancelled and a real submit. No console errors were logged.
- tests/logo-cache-check.cjs passed in the same Chromium. The page first caches a logo from a server that, like S3, sends its CORS header only to requests with an Origin, and the scene theme still tints it.
- Four public pages on a real Canvas server (sdsu.instructure.com: a course home, two syllabi and a modules page) loaded with the extension, dark mode off and then on with a light custom accent. There were no extension errors and no repeated failing requests. All 696 measured text elements met WCAG AA, and primary buttons and the skip link reached 5.56:1 or better.
- The WebP artwork was compared with the PNG originals: PSNR 33.5 to 37 dB, with no visible difference at twice the displayed size.

Scope of verification
The Chromium and Firefox checks used local synthetic pages and temporary profiles. The real Canvas check viewed public pages without signing in, so the dashboard, planner, grades and notifications ran only against the synthetic pages. Signed-out pages return 401 from the Canvas API; the extension logs these and does not retry them on every page update.
No school login or Openverse search was used.

Build/install
Run powershell -ExecutionPolicy Bypass -File build.ps1.
Load dist/chrome as an unpacked Chromium extension, or dist/firefox/manifest.json in Firefox's temporary add-on loader.
The build also creates dist/Better-Canvas-3.3.2-Chromium.zip and dist/Better-Canvas-3.3.2-Firefox.zip.
For an already loaded unpacked extension, reload the extension itself, then refresh the Canvas page.
